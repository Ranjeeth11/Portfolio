AI-Powered CAD Extraction & Quantity Estimation Platform

A geometry-first extraction pipeline that automates quantity estimation directly from DXF and DWG structural drawings — combining spatial reasoning, OCR fallback, and vision AI with a production-grade validation layer.

Quantity Estimation
View case study

Engineering challenge

Structural drawings mix precise vector geometry with inconsistent annotation conventions. Reliable quantity estimation requires reconciling both — while flagging uncertainty rather than guessing.

Solution

A geometry-first pipeline parses DXF/DWG entities directly, falls back to OCR and vision AI for annotation gaps, and applies semantic validation with confidence scoring before figures reach the estimation layer.

Scale & capability

A production database schema of 50+ tables backs 20+ specialized calculation engines covering distinct structural quantity types.

DigiDARA AI Voice Agent

A production bilingual English/Tamil voice-sales agent using real-time speech-to-speech AI for customer conversations and lead qualification.

  • Python
  • FastAPI
  • React
  • OpenAI Realtime API

Customer→ Voice/Telephony→ Real-Time AI→ ChromaDB + BM25→ Conversation→ Lead Qualification→ CRM
View case study

Engineering challenge

Bilingual, real-time speech-to-speech interaction demands language-specific turn-taking and low-latency retrieval, on top of a telephony stack that had to be swapped mid-flight.

Solution

Hybrid retrieval combining ChromaDB and BM25 grounds the agent during live calls. A mid-flight migration from Twilio to Plivo was executed with signed webhooks and CORS/CSP hardening.

Capability

Handles bilingual English/Tamil conversations end-to-end, from lead qualification through to CRM handoff.
